# 任务 B：重构遗留代码（行为必须完全不变）

同目录的 `legacy.py` 是一段真实项目里挖出来的"屎山"：能跑，但没人敢动。

你的任务：**重构 `legacy.py`**，让它干净、清晰、高效，但**对外行为 100% 不变**。

## 什么算"对外行为不变"

`legacy.py` 里有一个公开函数：

```python
process_orders(orders: list[dict], config: dict) -> dict
```

- 对任何相同的输入 `(orders, config)`，重构后必须返回**完全相同**的结果（相同 key、相同 value、相同顺序语义）。
- 相同的异常输入要抛出相同类型的异常。
- 你可以自由增删内部辅助函数、改数据结构、改算法。

## 怎么验证你没改坏

同目录有 `test_legacy.py`（一组特征测试，锁定了当前行为）。运行：

```
python -m pytest test_legacy.py -q
```

重构前后都必须**全部通过**。评测会用一套【你看不到的】更严格的对拍测试，随机生成上万组输入，逐字段比对 legacy 原版和你的重构版的输出——任何一个字段不一致都算失败。所以别只盯着可见测试调，要真正保持语义等价。

## 目标

- 把 90 行的大函数拆成职责清晰的小函数。
- 消除其中的性能问题（注意数据规模：orders 可能上万条）。
- 去掉死代码、魔法数、被吞的异常、布尔陷阱等坏味道。
- 命名要能自解释。
- 直接改 `legacy.py` 这个文件（覆盖它）。保留 `process_orders` 的签名。

改完自己跑一遍 pytest 确认全绿再交付。
